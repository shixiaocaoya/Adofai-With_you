## 安装

1. 游戏先装好 **UnityModManager**（UMM）；
2. 解压下载的 zip，得到 `With you` 文件夹；
3. 把整个 `With you` 文件夹放到：
`<游戏目录>\\\\Mods\\\\`
最终路径应为 `<游戏目录>\\\\Mods\\\\With you\\\\WithYou.dll` + `Info.json`；
4. **通过 Steam 启动游戏**，UMM 列表里能看到 **With you** 即安装成功；
5. 进选曲场景后走到的浅蓝色「多人游戏」地板进入多人界面。

## 更新

* 游戏启动时会自动检查版本：有新版本时不会出现入口地板，屏幕顶部会显示更新提示和下载地址；
* 更新方法：到 Releases 下载最新 zip → 解压覆盖 `Mods\\\\With you` → **重启游戏**（DLL 不能热替换）；
* UMM 的 Mods 页面选中 With you，也能看到当前版本和更新步骤。

## 多人玩法

1. 进多人界面 → 邮箱 + 密码登录（注册需要邮箱验证码；**每次进入都要重新登录**，只记住邮箱）；
2. 房主：填房间名 → `选择谱面`（游戏内文件浏览器，支持 `.adofai` / `.zip`）→ 上传并创建房间；
3. 其他人：大厅点「加入」→ 自动下载谱面并校验；
4. 全员点「准备」→ 房间页 **5 秒倒计时** → **黑屏过渡进谱面** → 谱面里再静止停留 **5 秒**（可以先读谱）→ 所有人**同一时刻**开始；
5. 左侧实时排行按 **XPerfect** 排序；打完结算 → 10 秒回房间。

房主功能：`更换谱面`、`移交房主`、`调整判定宽度`、打谱时左下角 `结束游戏` / `关闭房间`。

## 功能一览

### 竞速

* **同步开局**：起跑时间由服务器统一决定，不按键、不抢跑，所有人同一时刻开打；开局前有 5 秒房间倒计时。
* **判定宽度**：房主可以在房间页选「**宽判 / 标判 / 严判**」，所有人生效；其他成员只显示当前值。
* 实时排行按 XPerfect 显示，结算按 XPerfect 排名，支持 DNF（掉线 / 超时）。

### 房间 \& 大厅

* 房间页：玩家列表（准备 / 完成 / 掉线状态）、聊天、**一个按钮切换 准备 / 取消准备**、更换谱面、判定宽度、离开房间。
* 聊天：**回车发送**，支持历史记录（最近 100 条，进房自动补发）。
* 大厅：每个正在比赛的房间显示 **进度条 + 曲长**，按谱面**轨道时间**计算。
* 大厅四角信息：左下角实时时钟、右上角当前在线人数、右下角游戏版本与模组版本。
* 通知支持**堆叠显示**，多条提示不会互相覆盖。

### 管理员（OP）

* 被设为管理员的玩家，在房间成员列表里**名字是橙色**，并带有 `\\\[管理员]` 后缀；
* 管理员在房间里拥有**和房主一样的权限**：更换谱面、调整判定宽度、开始 / 结束本局、关闭房间、移交房主。

## 服务器

客户端内置两个 IP（北京 / 美国），连不上会自动切换；右上角会显示当前连的是哪台。
如果连不上，先确认游戏有网络、防火墙没有拦截 17800 端口。

## 常见问题

* **UMM 列表里没有 With you**：确认 `Mods\\\\With you\\\\WithYou.dll` 和 `Info.json` 都在；
* **进游戏崩溃 / 报错**：先删掉 `Mods\\\\With you\\\\withyou.log` 再启动，日志会重新生成，定位不了可以带日志反馈；
* **收不到验证码**：先看垃圾箱；也可以让服主在服务端控制台看兜底验证码；
* **提示有新版本**：按上面的「更新」步骤覆盖安装；
* **聊天打不了字 / 选谱窗口自己关**：更新到最新版本（0.7.7 起已修复）；
* **服务器连接失败**：土豆服务器问题，等我修复。
